# marcodemoja.github.io

Personal profile site for Marco De Moja, served with GitHub Pages at https://marcodemoja.github.io/.

- `index.html`: English page (x-default)
- `it/index.html`: Italian page

Plain static HTML, no build step. Both pages carry hreflang links to each other, and `sitemap.xml` lists both. `robots.txt` points to the sitemap for Google Search Console.

To verify the property in Search Console with the HTML file method, add the `googleXXXX.html` file Google provides to the repository root.
